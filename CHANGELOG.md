# Changelog

All notable changes to this repository are listed here. For changes to the API itself, see <https://popnow.ai/docs/changelog>.

## 1.0.0 — 2026-10-19

- OpenAPI 3.1 spec for the PopNow API (`openapi.yaml`), provided under the MIT License.
- Examples in curl, Python (standard library) and Node.js (no dependencies): list models, quote, text to image, image to video, poll a task, upload a file, receive and verify webhooks.
- Importable n8n workflow (`examples/n8n/popnow-workflow.json`).
- Markdown docs: quickstart, authentication, tasks, media, webhooks, idempotency, errors, rate limits, assets, recipes, production checklist, ComfyUI and OpenAI Videos compatibility.
- `llms.txt` and `llms-full.txt`, generated by `scripts/build_llms.py`.
